# 調査メモ 全機能所有先棚卸しの件

Godot 4.7.1改変sourceとgdweb書き出し器から、現在の採用範囲を抽出した棚卸し。
調査日: 2026-08-12

この表は現行sourceの接続関係を示す。成果物の完全性や表示同値性の保証ではない。

## 5分類

| 記号 | 分類 | 判定基準 |
|---|---|---|
| G | Godot側 | EditorまたはWasmに現行実装があり、gdweb書き出し器が入力を許可 |
| B | Browser側 | HTML、CSS、Canvas 2D、Web APIが表示や入出力を実行 |
| X | 排除 | build、ClassDB、resource検査、scene検査、script検査で有効な入力経路を遮断 |
| K | 候補 | 計画だけ。現行の書き出し経路なし |
| U | 未実証 | 部品はあるが、書き出し境界の不整合または比較試験不足 |

`G→B`は状態をGodotが所有し、確定値だけをBrowserが描画する境界。`U(G→B)`はその経路がsourceにあるが、採用済みと言い切れない状態。

| `gdweb/build/build_runtime.sh` | SCons option、明示module |

| `modules/gdweb/editor_export_platform_gdweb.cpp` | exact node 31型、Texture2D 4型、script検査、GUI property、PCK |
| `modules/gdweb/config.py` | gdweb moduleのEditor限定 |

## 過不足と矛盾

| 項目 | 現行sourceの判定 |
|---|---|
| 分類 | G/B/X/K/Uの5分類。実装と候補を分離 |
| build profile | 許可表ではなく、44件の無効class表。表にないclassは残り得る |
| 2D物理 | `disable_physics_2d=no`、`godot_physics_2d=yes`。sceneは3型だけ許可 |
| GUI | 基本GUI全件ではなくexact 24型。派生classの自動許可なし |
| Sprite/2D | `Sprite2D`だけscene許可。`AnimatedSprite2D`、`Line2D`、`Polygon2D`、`TileMapLayer`は非許可 |
| Texture2D | `ImageTexture`、`CompressedTexture2D`、`PortableCompressedTexture2D`、`AtlasTexture`の4型だけ |
| Canvas | clip、無texture矩形、texture矩形、primitive、無texture triangle polygonだけ |
| Audio | Web Audio経路はlink。`AudioStreamPlayer`と`AudioStreamWAV`はexact許可済みだが未実証 |
| PCK | 初期PCK、到達依存だけの遅延PCK、hash付きmanifest、cold/warm cache |
| Text | FreeType、MSDFGen、TextServerFallbackが明示module。Canvas文字commandは遮断 |
| Network | Fetchと`HTTPRequest`の部品はlink。gdweb専用の許可origin表なし |
| ClassDB制限 | sceneはexact検査。GDScriptは禁止identifier表だけで、全ClassDB APIの正の許可表ではない |

## 現在の出力経路

```text
Godot Editor
  ├─ selected scene・依存resource・autoloadの検査
  ├─ GDScriptの圧縮binary token化
  ├─ 初期PCK一つ
  └─ 先行HTMLと共通template
       ↓ startGameがmain PCKを先読み
Godot Wasm
  ├─ SceneTree・GDScript・2D物理
  ├─ Node2D command → Browser Canvas 2D
  └─ exact Control状態 ↔ Browser DOM/CSS/event
```

OpenGL、WebGL、Vulkanの代替経路は作らない。`gdweb_2d=yes`と`opengl3=yes`または`vulkan=yes`の併用はbuild error。WebGL JS部分もgdweb buildで除去。

Containerの配置演算はGodotが正本。BrowserはGodot計算済みの親相対matrixとsizeをnested absolute DOMへ同期。FlexboxやCSS Gridで再配置しない。DOM所有ControlのCanvas visibility layerは0。

N05/N06で`Control`、`Label`、`Button`、`Panel`、`ColorRect`の親17°回転、0.5/2倍scale、pivot、RTL、z、pointer、focus、disabledをnative/Web比較済み。N08で回転親のclipとhit targetを比較。`overflow:hidden`単独の1 px境界差を`clip-path:inset(0)`で固定。ButtonのdisabledはGodotと同じくfocus・Tab対象のためHTML `disabled`を使わず、`aria-disabled=true`とevent guardでsignalを抑止。全classの完全分類はTheme、負scale等の残条件があるためUのまま。

N10でexact Container 12型を各2子、親303×139でnative/Web比較済み。Godotのlocal矩形、minimum size、DOM matrix、DOM順が一致。HBox、Grid、HFlowのRTL、Marginの四辺差、Aspect 1.7も一致。文字minimum size、他stretch mode、複数行Flow、3列以上Gridは未実証のためUのまま。

現行の`gdweb_dom_sync()`は毎frameにSceneTree全体を再帰走査し、exact Controlをすべてupsert。Browser側は`WeakMap`の前回値比較でCSS mutationを抑制。dirty集合と一括差分送信はK。root矩形の再読みは`ResizeObserver`とwindow resize時だけ。

### 登録済みだがscene許可外

| 群 | class | 分類 |
|---|---|---|
| 基本GUI | `HScrollBar`、`VScrollBar`、`Popup`、`PopupPanel`、`TextureRect`、`NinePatchRect`、`ReferenceRect`、`TabContainer`、`TabBar`、`HSeparator`、`VSeparator`、`TextureButton`、`ScrollContainer`、`TextureProgressBar`、`ItemList` | U。scene exportはX、ただしClassDBは残る |
| abstract/support | `BaseButton`、`Range`、`ScrollBar`、`Slider`、`Separator`、`ButtonGroup` | Gの内部契約またはresource。exact scene nodeに数えない |
| advanced GUI | `ADVANCED_GUI_DISABLED`配下 | X。build時にClassDB登録しない |
| video | `VideoStreamPlayer`と関連型 | U。登録済み、scene許可外 |

scene許可外でも、GDScriptの`ClassName.new()`を包括的に禁止する機構はない。scene検査だけをruntime不在の根拠にしない。

## GUI propertyとevent

### 共通property 36件

```text
unique_name_in_owner, process_mode, process_priority,
process_physics_priority, process_thread_group, physics_interpolation_mode,
auto_translate_mode, editor_description, visible, modulate,
custom_minimum_size, custom_maximum_size, propagate_maximum_size,
clip_contents, layout_mode, anchors_preset,
anchor_left, anchor_top, anchor_right, anchor_bottom,
offset_left, offset_top, offset_right, offset_bottom,
grow_horizontal, grow_vertical, rotation, scale,
pivot_offset, pivot_offset_ratio, size_flags_horizontal,
size_flags_vertical, size_flags_stretch_ratio, layout_direction,
z_index, script
```

これらは書き出し検査の許可property。すべてをDOM属性として送る意味ではない。layout入力はGodotがmatrix/sizeへ演算。processとscriptはGodot内のみ。

### 型別property

| exact class | 許可値 |
|---|---|
| `Button`、`CheckBox`、`CheckButton` | `disabled`、`toggle_mode`、`button_pressed`、`action_mode`、`button_group`、`text` |
| `Label` | `text`、font color、font size |
| `LineEdit` | `text`、`placeholder_text`、`editable`、`caret_column`、`secret`、font color、font size |
| `LinkButton` | button共通値、`text`、`uri`、font color、font size |
| `ProgressBar` | `min_value`、`max_value`、`step`、`value`、`show_percentage` |
| `HSlider`、`VSlider` | `min_value`、`max_value`、`step`、`value`、`editable` |
| `Panel` | `theme_override_styles/panel` |
| `ColorRect` | `color` |
| exact Container 12型 | theme以外の保存property全件と`theme_override_constants/*` |

DOMへ送る共通値は親相対matrix、size、alpha、visible、clip、z、font size/color、RTL。RGB modulateは白、alphaだけ保持。対応外の非既定値は書き出しwarningと固定fallback。

`Panel`は`StyleBoxFlat`のbackgroundだけ。border、expand、corner、shadow、skewはwarning。`LinkButton.uri`は安全なscheme以外を`#`へfallback。

DOM eventはactivate、text input、selection、range valueの4種。Tab/focusはBrowser。Godotへ状態とsignalを戻す。

`library_gdweb_dom.js`のLineEdit位置変換は`Array.from()`でDOMのUTF-16位置をUnicode code point数へ変換。N09で`ASCII日本😀é`のDOM全文範囲`[0,11]`をGodotの`[0,10]`へ変換し、空、部分、全文selectionを実証。実OS IME候補操作は未実証。

## Canvas 2D命令

Browser側の命令番号は5種。

| 番号 | Godot command | Browser処理 | 制限 |
|---:|---|---|---|
| 0 | item clip、`TYPE_CLIP_IGNORE` | `save/rect/clip/restore` | 矩形clip |
| 1 | 無texture `TYPE_RECT` | `fillRect` | RGBA変調あり |
| 2 | 無texture `TYPE_PRIMITIVE` | point/line/fill | 先頭色だけを使用 |
| 3 | 無texture `TYPE_POLYGON` | triangle pathのfill | triangle index必須、先頭色だけを使用 |
| 4 | texture `TYPE_RECT` | `drawImage` | region、flip H/V、transpose、filter、RGB tint、alpha |

`TYPE_TRANSFORM`はGodot側で現行matrixを更新。他のcommand typeはruntime warning後に破棄。texture付きprimitiveとpolygonも破棄。Canvas文字、style box、mesh、multimesh、animation sliceはscript検査で遮断。

`draw_texture`、`draw_texture_rect`、`draw_texture_rect_region`、polygon系の一部はwarning付きfallback。tiling、UV、頂点ごとの色の同値性はない。円弧、Canvas文字、独立したpolyline APIを採用済みとしない。

script検査で常に遮断するCanvas API。

```text
draw_msdf_texture_rect_region, draw_lcd_texture_rect_region,
draw_style_box, draw_primitive,
draw_string, draw_multiline_string,
draw_string_outline, draw_multiline_string_outline,
draw_char, draw_char_outline,
draw_mesh, draw_multimesh,
draw_animation_slice, draw_end_animation
```

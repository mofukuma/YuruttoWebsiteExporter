# 正常系機能組合せ試験の件

## 目的

採用する2D機能を、重複しない正常画面へまとめた比較試験表。
同じGodot 4.7.1場面を標準Godotとgdwebで実行し、公開状態と最終表示を比較。

不正入力、非対応API、書き出し失敗のfixtureは対象外。未実装機能は期待仕様までを固定し、未実証として扱う。

## 同値類のまとめ方

- 平行移動は正負座標と親子合成を一類。画像、図形、GUIで同じ数だけ増やさない。
- 回転は0度、90度、任意角の三類。画像とGUIで描画先の差だけ確認。
- 拡縮は`0.5`、`2.0`、負scaleの三類。負scaleは画像、正scaleはGUIへ割当。
- 画面端は完全内、1px接触、一部外、完全外の四類。Canvas選別とclipで共有。
- zは同一親、別親、clip内外の三類。CanvasとDOMを各一画面で確認。
- 文字入力はASCII、日本語、絵文字を含むUnicodeの二類。selectionは空範囲と部分範囲。
- 値入力はmin、中間、maxの三類。stepと方向はHSlider、VSliderで分担。
- 寸法変更は初期、小→大、大→小の三類。一つのviewport試験で連続確認。
- 音声は開始、中間、終了の三時点。一つの音源と一回の再生で確認。

## 共通比較規則

### 入力

- 同一`.tscn`、`.gd`、Resource、viewport内部寸法、device scale 1
- 標準Godotは4.7.1 native。gdwebは同じcommitの実書き出し成果物
- 固定deltaが必要な物理とanimationは同じphysics tick数で停止
- font読込完了後、同じframe番号または同じ公開状態到達後に撮影
- 背景色と透明合成を固定。比較画像は同じ幅、高さ、色空間

### 公開状態

各場面が`GDWEB_NORMAL_STATE=<JSON>`を一回だけ出力。標準GodotとWebでJSONを完全一致。

共通項目。

- `case`: 試験ID
- `frame`: 比較frame
- `viewport`: 内部幅と高さ
- `nodes`: 対象nodeの位置、回転、scale、visible、z
- `signals`: signal名ごとの発火回数
- `values`: GUI、物理、音声、Resourceの場面固有値
- 浮動小数はfixture側で小数6桁へ丸め

### 表示

- PNG全体の正規化MAE `< 0.01`。表示誤差1%未満
- 幾何位置は公開状態で絶対誤差`0.01px`以下
- Chromiumの最終DOM矩形は標準Godot矩形に対して各辺`1px`未満
- 回転角は`0.01°`以下。scaleは各軸`0.0001`以下
- 色は各RGBA channel絶対差`1/255`以下
- zとclipは指定probe pixelとhit targetの完全一致
- 文章、selection、Tab順、ARIA値、signal回数は完全一致
- Webが要求したCanvas contextは`2d`だけ

font raster差で全体MAEを満たしても、位置、DOM文字、selection、ARIAの不一致は失敗。

### 終了

- 標準Godot、gdweb書き出し、Chromium試験の終了code 0
- console error、page error、Godot `ERROR`、crash、timeout 0件
- browser、page、HTTP serverを`finally`で終了
- 試験終了後にfixture由来のGodot、Chromium、Node、HTTP server process 0件
- screenshot、state、log、結果JSONを`.tmp/gdweb/normal-matrix/<ID>/`へ保存
- 固定sleepを使わず公開状態を短周期で確認。画面内の成立待ちは0.5秒以内
- import、native、exportの再生成は入力または成果物hashが変わった場合だけ

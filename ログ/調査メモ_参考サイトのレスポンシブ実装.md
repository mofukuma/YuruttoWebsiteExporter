# 参考サイトのレスポンシブ実装

## 正本

`../ynote/参考サイト/data/sites/jp24-daito-manabe/`のdesktop、mobile、DOM、画像。別の設計資料は使用しない。

## 実装判断

- [Godot Size and anchors](https://docs.godotengine.org/en/latest/tutorials/ui/size_and_anchors.html): 異なる画面比率ではControlのanchorとoffsetで追従。
- [Godot UI](https://docs.godotengine.org/en/stable/tutorials/ui/index.html): 文字、入力、配置はControlとContainerを基本部品として構成。
- [Godot Multiple resolutions](https://docs.godotengine.org/en/latest/tutorials/rendering/multiple_resolutions.html): GUIは画面幅へ追従し、縦方向の表示量を保つ構成が適する。

1440 pxでは左右24 px、390 pxでは12 pxの余白。760 px以下をmobileとして、header、hero統計、作品一覧を一列へ変更。SceneTreeを正本にし、Canvas 2Dへ背景、線、画像、DOMへ文字、入力、操作意味を出力する。

## 意味DOMの表示検証

Godot 4.7の`Window.title`はウィンドウ装飾用の名前。Web本文ではない。gdwebでは`Window`要素の本文へ同じ文字を入れず、`aria-label`へ保持する。

`LineEdit.placeholder_text`は入力値とは別の案内。作品側では空欄時のLabelとして明示し、入力後に非表示とする。

- [Godot Window 4.7](https://docs.godotengine.org/en/4.7/classes/class_window.html)
- [Godot LineEdit](https://docs.godotengine.org/en/stable/classes/class_lineedit.html)
